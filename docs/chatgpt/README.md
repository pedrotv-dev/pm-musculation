# Missions ChatGPT — habillage, sons, bruitages

Ordre conseillé : **1 → 2 → 3** (le style d'abord ; l'identité sonore et les bruitages s'accordent ensuite sur la direction choisie).
Tout se fait **par petites étapes**, une PR chacune, avec un arrêt à chaque étape (voir le protocole dans `00-contrat-technique.md`).

| Fichier | À envoyer à ChatGPT | Contenu |
| --- | --- | --- |
| `00-contrat-technique.md` | (lu par chaque mission) | règles, fichiers autorisés, événements `pm:fx`, mascotte, vérifications |
| `01-design-et-animations.md` | mission 1 | style, animations, mascotte (12 stades), célébrations |
| `02-sons.md` | mission 2 | jingles de récompense, mélodie de fin de repos |
| `03-sfx.md` | mission 3 | bruitages d'interface |
| `04-ressources-ascent.md` | mission 4 | décor montagne, Korv grand format, pictogrammes, hexagones et succès, expressions du guide |

La direction artistique des **minuteurs** (barre de repos) est volontairement laissée de côté : à décider ensuite.
